# GridPulse

Autonomous cascading-blackout interceptor powered by **FalkorDB** (GraphBLAS sparse matrix engine) and **MCP** SCADA agents.

GridPulse traces 4–6-hop cascading thermal overloads across a 500 kV transmission grid in ~1.4 ms, dispatches local BESS power, and sheds only Tier-3 industrial loads, so Tier-1 critical infrastructure (St. Jude Regional Trauma Center) stays online.

See [`docs/SPEC.md`](docs/SPEC.md) for the full project context and technical specification.
